# Improved YOLOv11

Complete snapshot of the local project directory `D:\USM\yolov11 - upload`.

## Downloads

- [Complete project ZIP: source code, datasets and all trained weights](https://github.com/250810520/improved-YOLOv11-/archive/refs/tags/v1.0.0.zip)
- [Latest repository ZIP](https://github.com/250810520/improved-YOLOv11-/archive/refs/heads/main.zip)
- [Browse project files](yolov11-upload/)

The project contains all 4,851 original files, including 17 PyTorch weight files, the datasets, training scripts, model configurations, source code, documentation, and experiment outputs. Original file contents are preserved. GitHub generates the complete ZIP directly from the published repository tag.

## File verification

`SOURCE_MANIFEST.json` records the byte size and SHA256 of every original file. Use this manifest to verify the extracted `yolov11-upload` directory.

## Usage

Extract the complete project ZIP and open the `yolov11-upload` directory inside it. Local dataset and weight paths in the original scripts may need to be adjusted on another computer.
